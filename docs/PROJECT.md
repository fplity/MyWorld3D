# 方境 · BlockHorizon 项目说明

## 项目定位与完成范围

Java 桌面端、第一人称、单人 3D 体素沙盒。玩家在由种子决定的有限世界中探索，采集材料、合成、建造，管理生命、饥饿和体力，并逐步发现小屋、宝箱、遗迹与隐藏伙伴。

本次完成目标是将已经存在的玩法整合为能够运行、保存、复现构建和转发给朋友的 1.1.0 版本。不是对完整 Minecraft、联机系统、无限地图、模组平台或商业发行认证的承诺。

## 玩法系统

1. 世界：噪声高度地形、六种环境类型、洞穴、树木、海岸与晶体。地图为 64×64，高度 40；一个种子不保证同时出现所有环境类型。
2. 角色：第一人称视角、移动/冲刺/跳跃、持续游泳上浮、重力和碰撞、坠落伤害、创造模式与飞行。
3. 建造：体素射线选块、持续采集进度、方块放置、玩家占用判断、九格热栏、块类型对应颜色及像素贴图。
4. 资源：背包计数、木板/石砖/星辉石/树篱四种配方、浆果、无限建材创造模式。
5. 生存：生命、饱食、体力、食物、恢复、死亡与 R 重生。单人暂停和背包/地图的模拟行为不同，详见 README。
6. 天气：约五分钟昼夜、太阳/月亮、星空、云层、雾、雨、雷电与流星事件。
7. 生物：友善小苔团、夜间影徘徊者、战斗和战利品。模型与行为为独立简化实现。
8. 探索：固定规则生成的小屋、一次性宝箱奖励、遗迹、阶段任务和成就。回响伙伴是保留的小惊喜：唤醒后跟随玩家，并在一定条件下帮助恢复生命。
9. 辅助：中文标题界面、随机种子、背包与合成、旅者地图、暂停、HUD 显隐、调试、截图、程序化音效。
10. 保存：一个 JSON 存档槽，正常退出/自动/手动保存、有效旧快照备份、方块编辑/宝箱/任务/成就/角色/背包/伙伴和新增建筑/旅行进度持久化。生物个体位置与天气瞬时状态不完整持久化。

## 技术结构

| 模块 | 职责 |
|---|---|
| `world` | 种子、噪声、地形、块定义、压缩坐标、脏区块与 DDA 射线 |
| `render` | 运行时图集、表面网格、分块重建、视锥剔除、天气和粒子 |
| `player` | 碰撞移动、生存数值、物品与配方 |
| `entity` | 生物状态、战斗、伙伴 |
| `screen` / `ui` | 画面切换、游戏循环、输入、中文 HUD、自动验证钩子 |
| `save` | 独立用户数据路径、校验、迁移、备份与落盘 |
| `audio` | Java Sound 合成音效 |
| `desktop` | LWJGL 窗口启动与自动验证成功标记 |
| `scripts` | 构建/真实窗口验证/裁剪运行时/便携打包 |

Java 编译目标 17；本机用 JDK 25 构建。LibGDX 1.14.2、LWJGL 3.4.1、Gradle Wrapper 9.6.1 固定版本。字体为随包提供的 LXGW WenKai GB Lite。便携包运行时来自本机 OpenJDK 25.0.1，相关许可保留在 `runtime/legal/`。

## 修复为何必要

- 旧 Wrapper 失败仍返回 0：现在准确传递失败，测试和发布脚本不会继续错误打包。
- 旧关闭路径只调用 Game.dispose：现在显式销毁当前 Screen，游戏存档与 GPU 资源释放执行。
- 旧射线在整数正方向第一步距离为 0：现在到下一整数平面的距离为 1/方向分量，选块/触及距离一致。
- 旧碰撞只看最终位置：现在每步不超过 0.2，并对阻挡边界做二分逼近，避免高速跨越薄阻挡物。
- 旧世界查询会因位掩码坐标绕回：先验证水平边界，再取压缩键。
- 旧存档直接覆盖：改成同目录临时文件、校验后的旧版本备份、替换与错误返回，并隔离安装目录和玩家数据。
- 旧每帧提交全部 64 区块：现在先做相机视锥判断；观察到常规测试视角提交 21/64 区块，不能据此宣称 FPS 提升比例。

## 分发、维护与已知边界

- 优先转发内置运行时的完整 Windows x64 ZIP。普通 Java 发行包保留给已经有 Java 的用户。
- 下载附带的 SHA256SUMS 对比文件完整性。校验不替代对软件来源的信任。
- 仓库私有，下载链接需要登录仓库账号或被授予访问权限；朋友可以接收所有者直接发出的 ZIP。
- EXE 未代码签名，无安装器、自动升级服务或远程遥测。游戏无需连接游戏服务器。
- 首次源码构建可能受 Maven 网络限制。Release 保留本次使用的离线 JAR 集合，但仍需要 JDK 和 Gradle。
- 当前测试是主会话自动验证，不是独立 tester 验收；Windows 实际窗口证据和 CI 证据分别记录。
- 未做长时间稳定性、各显卡型号、所有显示缩放设置、手柄/触屏、网络联机、Linux/macOS 实机或商业发行验收。

## 删除本地工程后的恢复

源码从 `https://github.com/fplity/MyWorld3D` 克隆恢复，安装包和离线依赖从 v1.1.0 Release 下载。用户数据目录和其他项目不属于工程删除范围；工程中的开发测试存档不对外归档。

```powershell
git clone https://github.com/fplity/MyWorld3D.git
cd MyWorld3D
.\gradlew.bat test build installDist --no-daemon
```

本地删除动作的最终结果由执行完成后的聊天与长期项目记录说明；这里不预先声称已删除。
